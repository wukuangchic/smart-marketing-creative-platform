# 项目记忆与交接

**更新日期：2026-11-10**

## 项目定位

为广告公司员工提供内部创意图片生成工作台。界面和创作流程参考 DSH Image Gen；本项目是独立 Web 平台，没有把 DSH 插件作为代码底座。

首期范围：

- 文生图、单张原图图生图。
- 百炼、Gemini 与智谱图像模型目录，文生图/图生图按单个型号能力开放；可同时选择任意已启用模型，按人民币参考成本升序展示，开始调用前必须确认预估费用。
- 自定义目标宽高；模型结果通过服务端图片处理等比填充并裁切到目标尺寸。
- 图片命名模板默认 `{标识}`，允许在编号前后加自定义文字，但必须且只能包含一次 `{标识}`；支持 `{日期}`（任务日期，YYYYMMDD）、`{模型}`（供应商模型 ID）和 `{员工姓名}` 通配符。`{标识}` 替换成 8 位 Crockford Base32 编号，前 4 位区分提示词，后 4 位按该提示词前缀连续递增。同一任务的所有模型共享一个连续序号区间，编号写入图片文件名及素材记录，供未来媒体消耗归因。
- 历史提示词列表提供“直接使用”，原样复用单条提示词并沿用它最近的前 4 位前缀；手动修改提示词或采用 DeepSeek 重构结果时生成新前缀。旧历史记录保留旧编号格式。
- 历史记录提供“一键复制”，将模式、提示词、命名模板、标签、模型及张数、画面比例和目标尺寸带回创意生产；图生图原图不复制，需重新上传。复制后不自动估价或生成，员工仍需手动点击“查看预估并生成”。历史记录页不提供删除按钮。
- 每个任务可以选择多个分类标签；标签为全体成员共用，名称不区分大小写且唯一。成员可新建标签，重复名称会拒绝创建并提示选择已有标签。任务与标签通过多对多关系保存，旧任务标签迁移时保留。
- 工作空间包含素材库：浏览生成素材缩略图，按标识、日期、多标签（满足任一或全部）、供应商和模型筛选，可多选并打包 ZIP 下载；历史记录每个任务提供一个包含其全部生成图的 ZIP。
- 工作空间导航包含“消耗统计”和“ROI 面板”两个待开发页面；当前不展示消耗或 ROI 数据。
- DeepSeek API 只用于历史提示词搜索、多选和一键重构，不作为图片生成模型。
- 共享历史、逐次成本估算、账单周期汇总、管理员配置和飞书白名单。
- 收入核算与媒体广告 API 暂缓。

## 当前实现

- Next.js / TypeScript 模块化单体，PostgreSQL 保存业务记录，pg-boss 使用数据库队列，Docker Compose 部署。
- 模型调用独立运行；一家模型失败不影响另一家。超时或状态不明时不自动重试，避免重复计费。
- 用户可搜索共享历史提示词并多选交给 DeepSeek `deepseek-flash` 重构；提示词正文不会写入重构审计日志，成功调用记录 token 用量。
- 历史任务 ZIP 和素材库 ZIP 都保留图片保存时的原文件名；素材库仅列出生成结果，不包含图生图输入原图。素材库批量 ZIP 下载限制为每批最多 100 张、总大小 500 MiB；单任务 ZIP 总大小上限也是 500 MiB。
- 百炼目录包含 Qwen Image、Wan、Z-Image；Gemini 包含 4 个图像型号（2.5 Flash Image 已弃用并有停服日期）；智谱包含 GLM-Image。模型 ID、能力和管理员可调整的参考单价见[图片生成模型与参考价格](model-pricing.md)。
- 原图和结果保存在服务器数据盘；图片长期保留。80% 提醒、95% 阻止新生成任务。
- 飞书 OAuth、回调和首位管理员登录已验证。两位引导管理员的 Open ID 保存在服务器环境中，不记录在仓库。
- 管理员入口为“API 配置”。在“飞书白名单”中添加后续员工，角色默认“成员”；仅授权管理员可管理 API、价格、汇率、账单和成员。
- DSH Image Gen 只作为 UI/交互参考；代码未从该项目复制。

## 未完成配置与业务边界

- 百炼、Gemini、智谱图像生成凭证和 DeepSeek 提示词重构凭证均已加密保存到服务器数据库并启用；密钥值不进入 GitHub 或项目文档。DeepSeek 只供提示词重构使用。
- 百炼和 Google Cloud Billing 账单只读连接尚待凭证和筛选范围；实际汇总账单不拆分成单张图片的实际费用。
- 需要配置独立于服务器的数据备份目标并完成恢复演练。
- 收入按广告消耗比例核算，客户间比例不同；正式数据源、规则和结算周期尚未确定。不要按图片数量或固定单张售价实现收入公式。
- 后续媒体 API 的平台、调用范围与授权方式待确认。

## 隐私与仓库边界

GitHub 仓库现为公开仓库；发布前已从当前文件和可达 Git 历史清除服务器公网地址、安装路径和数据盘设备标识，并检查常见密钥格式。仓库只保存应用代码、模板和不含生产值的部署示例。飞书 App Secret、管理员 Open ID、模型/账单凭证、数据库密码、加密密钥、服务器公网地址、SSH 私钥、TLS 私钥和生产图片均只保存在服务器或本机未跟踪配置中。后续改动仍须遵守此边界。

## 建议的下一步

1. 由管理员在“API 配置”录入并启用模型 API 凭证、Endpoint、价格和生效汇率，然后各做一次小额生成验证。
2. 让第二位管理员首次登录；新员工由管理员在网页白名单中添加为“成员”。
3. 配置独立数据库和图片备份，并完成恢复演练。
4. 取得账单只读凭证后，启用百炼和 Google Cloud Billing 对账。
5. 再确认收入统计口径和媒体 API 接入范围。
